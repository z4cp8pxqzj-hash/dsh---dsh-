# 大肥鱼桌宠

> DeepSeek 鲸鱼娘二创形象「大肥鱼」的透明桌面宠物：会走路、会眨眼、会聊天、会学习，还带着一肚子社区梗。

基于三视图素材（正面 / 侧面 / 背面）实现，Python + PySide6 无边框透明置顶窗口，内置便携 Python 运行时，解压即用。

## 功能一览

### 形象与动画
- 三视图行走：左右走用侧面（自动镜像）、向上走用背面、向下走用正面，转向时交叉淡化
- 动态眨眼：睁眼立绘逐像素分析眼型，运行时实时生成闭眼帧（正面 / 侧面），保留原画眉毛、睫毛、眼型
- 呼吸、摇摆、蹦跳、进食等细节动画，加减速惯性，散步中途自动休息
- 快速来回拖拽甩鱼，鱼会转圈转晕然后晕倒躺平，弹出「唤醒」面板

### 互动
- 左键单击：蹦跳 + 回嘴台词 + 弹出功能面板
- 左键拖拽：侧身朝向拖动方向，松手会说话
- 双击：喂食面板（小鱼干 / 蛋糕 / 棒棒糖 / 团子 / 钻石 / 大白饭）
- 右键：79% 概率弹出梗图气泡（`memes/` 里的网图 / 动图，支持 GIF 逐帧播放），其余时候冒一句碎碎念气泡
- 小概率（3%）右键触发放歌（`music/` 里的本地音乐，一首放完锁定 3 分钟冷却）
- 吃 5 碗大白饭触发「躺平」模式，30 秒后才肯起来

### AI 对话（Agnes API，OpenAI 兼容接口）
- 人设为高冷傲娇的「大肥鱼」，每句不超过 30 字，台词取材 DeepSeek / 鲸鱼娘社区梗
- 保留最近 40 条上下文，回答带随机语气词
- API 地址、模型名、Key 均可在菜单里修改，Key 使用 AES 加密后存入配置（`secure_key.py`），不落明文
- AI 代码生成：独立对话框输入需求，直接产出完整可运行代码，支持复制 / 保存到文件

### 记忆系统
- 对话记忆持久化在 `jiyi/chat_history.json`
- 按艾宾浩斯遗忘曲线衰减旧记忆，长期不引用的会自动淡忘
- 新一轮对话时按关键词检索相关旧记忆，拼进提示词让鱼「记得以前聊过什么」
- 菜单里可一键清除全部记忆

### 自主学习
- 空闲时自动打开文件夹「偷看」，小概率触发联网学习：DuckDuckGo 搜索热门话题，AI 总结成知识存入本地知识库
- 积累的知识有机会以「分享冷知识」的形式冒泡说出来

### 实用功能
- 三种移动模式：自由散步 / 跟随鼠标 / 原地待着
- 三档体型：小 / 中 / 大
- 鼠标穿透、窗口置顶、开机自启、回到屏幕内、显示 / 隐藏、一键重启
- 集成 DSH 启动器（PCL-Deepseek-Harness-Launcher），可一键拉起或移除

## 运行方式

### 方式一：便携版（推荐）

在 GitHub 页面点绿色「Code」→「Download ZIP」，解压后双击 `启动桌宠.bat` 即可。
也可以 `git clone`，效果一样。
无需安装 Python，`runtime/` 已内置完整解释器和全部依赖（约 155 MB）。

### 方式二：源码运行

```bash
git clone https://github.com/z4cp8pxqzj-hash/dsh---dsh-.git
cd dsh---dsh-
pip install -r requirements.txt
python pet.py
```

需要 Python 3.10+，依赖见 `requirements.txt`（PySide6、requests、pycryptodome）。

### 首次使用

右键系统托盘图标 → 「设置模型 / API」→ 填入 API 地址和 Key，即可开始聊天。

## 更换形象

把新的三视图（白底）放进程序目录后运行预处理脚本：

1. 准备 `正面.png` / `侧面.png` / `背面.png`
2. `python preprocess.py` —— 白底泛洪抠图 + 统一高度 + 生成托盘图标
3. `python preprocess2.py` —— 边缘去污 + 预乘 alpha 缩放，生成 187 / 238 / 306 三种尺寸精灵

梗图和音乐同理：想换直接往 `memes/`、`music/` 目录丢文件（png / jpg / webp / gif / mp3 / wav / ogg / flac）。

## 项目结构

| 文件/目录 | 说明 |
|-----------|------|
| `pet.py` | 主程序，全部桌宠逻辑（约 3200 行） |
| `run.py` | 启动器，供 bat 拉起主程序 |
| `secure_key.py` | API Key 的 AES 加解密管理 |
| `preprocess.py` / `preprocess2.py` | 三视图抠图、精灵多尺寸生成 |
| `sprites/` | 三视图精灵图（各尺寸）+ 图标 |
| `memes/` | 右键梗图素材（webp / gif / jpg） |
| `music/` | 右键放歌的本地音乐 |
| `jiyi/` | 记忆数据目录（聊天历史 / 知识库，自动生成，不入仓库） |
| `dsh laun/` | DSH 启动器（可选组件） |
| `runtime/` | 便携 Python 环境 + 依赖（约 155 MB，解压即用） |
| `启动桌宠.bat` / `start.bat` | 启动脚本（便携版 / 源码版） |
| `config.json` | 本地配置：城市、模式、体型、API 加密 Key（不入仓库） |
| `LICENSE` | MIT 协议 |

## 注意事项

- `config.json` 含加密后的 API Key，不要提交到仓库（`.gitignore` 已排除）
- 杀毒软件可能对新下载的 exe / Python 运行时误报，加信任即可
- 记忆与知识库都在 `jiyi/`，删除该目录即可彻底重置
